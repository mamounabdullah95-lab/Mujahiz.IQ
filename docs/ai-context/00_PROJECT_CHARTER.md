# Mujahiz IQ — Project Charter

## Product identity

Mujahiz IQ is an Iraqi B2B supplier discovery and procurement workflow platform.

The product should evolve beyond a static supplier directory into:

> A trusted Iraqi supplier network and structured RFQ workflow that helps buyers discover suitable suppliers, receive comparable quotations, document decisions, and build supplier-performance data.

## Primary user groups

- Buyers and procurement professionals.
- Suppliers and company representatives.
- Administrators.
- Platform Owner / Super Admin.

## Core product value

For buyers:

- Reduce time spent finding suppliers.
- Create structured RFQs.
- Receive and compare quotations.
- Maintain supplier and procurement records.
- Improve transparency and decision quality.

For suppliers:

- Maintain an accurate company profile.
- Receive relevant opportunities.
- Respond to RFQs efficiently.
- Build a measurable performance and trust record.

## Product principles

- Trust before growth.
- Verified and structured data before raw listing volume.
- Neutral marketplace behavior.
- Clear separation of roles and permissions.
- Arabic-first quality with complete English support.
- Mobile-friendly workflows for the Iraqi market.
- Progressive enhancement: introduce advanced automation only after the basic RFQ cycle works reliably.
- Production safety and data integrity take priority over delivery speed.

## Current strategic priorities

1. Stable registration, authentication, and role-based access.
2. Supplier ownership/claim and reliable profile linking.
3. A complete RFQ cycle with correct notifications.
4. Search across the full supplier dataset, not only the first loaded page.
5. Measurable value for buyers and suppliers.
6. Gradual catalog and quote-drafting capabilities.
7. Commercial plans only after real usage demonstrates value.
