# حزمة ذاكرة مشروع مجهّز

هذه الحزمة هي المرجع المختصر والثابت الذي يجب أن يعتمد عليه ChatGPT وCodex بدل إعادة كتابة تاريخ المشروع وقواعد الأمان والـBaseline داخل كل برومبت.

## طريقة الاستخدام

1. انسخ ملفي `AGENTS.md` و`CODEX.md` إلى جذر مستودع المشروع.
2. انسخ مجلد `docs/ai-context` بالكامل إلى المستودع.
3. سيقرأ Codex ملف `AGENTS.md` تلقائيًا، وهو يوجّهه إلى `CODEX.md` والملفات ذات الصلة.
4. في كل مهمة جديدة، استخدم `09_PROMPT_TEMPLATE.md` ولا تكرر المعلومات الموجودة في الملفات المرجعية.
5. حدّث `01_CURRENT_BASELINE.md` فقط عندما يتغير الـCommit المنشور أو أعداد Production أو حالة النشر.
6. أنشئ ملف حالة مختصر من `10_TASK_STATE_TEMPLATE.md` عند نقل العمل إلى جلسة أو Fork جديد.

## قاعدة العمل الجديدة

- المعلومات الثابتة تبقى في هذه الحزمة.
- المعلومات المتغيرة تبقى في ملف الـBaseline.
- البرومبت يذكر فقط هدف المهمة، نطاقها، معايير القبول، الاختبارات، ونقطة التوقف.
- المراجعة تكون للـDiff الحالي أو الوحدة المتأثرة، وليس للمشروع كله، إلا عند وجود سبب حقيقي.
