## 1. Use of this register

- `Recommended` means the schema design adopts the direction, but it is not implemented.
- `Open` requires the named approver before the stated phase.
- `Resolved` means the named decision is approved or settled for the explicitly recorded scope and evidence; it does not imply implementation unless the row says so.
- `Partially implemented` means the declarative schema contract exists but a named runtime or hosted gate remains.
- `Deferred` keeps a compatibility seam but excludes implementation from the initial migration.
- `Rejected` records an alternative that must not reappear without new evidence.
- Changing a resolved recommendation requires an ADR or an explicit change to this register and its dependent design sections.
- No row authorizes SQL, RLS, hosted Supabase work, Firebase changes, data movement, or Production access.
